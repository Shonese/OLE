# OLE Focus Pause

無意識なSNS・動画サイトの閲覧に短い介入を入れ、だら見を抑える個人用ブラウザ拡張機能です。

## 目的

YouTube、X、Instagramなどを開く直前に待機や呼吸などの「考え直す余白」を作ります。完全な遮断だけではなく、必要な利用は許可しながら意図的な閲覧を促すことを目的とします。

## MVP

- 対応ブラウザ：Firefox
- 初期対象サイト：YouTube、X、Instagram
- 任意のURLまたはドメインを対象に追加可能
- サイト別・曜日別・分単位のスケジュール設定
- 時間帯ごとのモード：自由／介入／ブロック
- 介入：待機、呼吸、目的入力、注意文、代替行動
- 例外許可：完全禁止、時間限定許可、理由入力、複数確認
- ローカル保存の基本統計：アクセス試行回数、曜日・時間帯別の傾向

設定と統計はブラウザ内にのみ保存します。アカウント、同期、広告、課金、外部へのデータ送信は行いません。

## 将来対応

- Chrome対応
- YouTube Shortsやホーム画面など、ページ内要素単位の制御
- より詳細な統計・可視化

## 開発方針

Firefox向けに実装・検証しますが、将来のChrome対応を前提に、標準的なWebExtensions APIを中心に利用します。ブラウザ固有の処理は分離し、設定・スケジュール・統計のロジックはブラウザ非依存にします。

## 使い方（Firefox）

1. Firefoxのアドレスバーで `about:debugging#/runtime/this-firefox` を開く。
2. **一時的なアドオンを読み込む** を選ぶ。
3. このプロジェクトフォルダ内の `manifest.json` を選ぶ。
4. YouTubeを開く。初期設定では、5秒の呼吸アニメーション後に閲覧を許可する画面が出る。
5. ツールバーの拡張機能アイコンを押して、ブラウザの設定画面を開く。自由・介入・ブロックと待機時間を変更後、保存してYouTubeを再読み込みする。

ブロック時には「現在のタブだけ5分許可」を選べます。介入を完了した対象サイトのタブがある間は、新しく開く同じ対象サイトのタブをブロックします。許可済みタブを閉じると、次の対象サイトタブでは再び介入が表示されます。初期状態では対象サイトは未登録で、YouTubeを含む任意のドメインを設定画面から追加できます。曜日・時間帯ごとのルールはサイト別に登録でき、日付をまたぐ時間帯にも対応します。
